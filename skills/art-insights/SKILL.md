# art-insights

Deep analytics for the generative art portfolio with visual dashboards, gap analysis, and inspiration engine.

## Quick Actions

```bash
art-insights              # Full portfolio dashboard
art-insights categories   # Category breakdown with piece lists
art-insights timeline     # Creation history visualization
art-insights complexity   # Complexity distribution
art-insights gaps         # Identify portfolio gaps
art-insights inspire      # Daily inspiration picker
art-insights compare a b  # Compare two algorithms
```

## Features

### Visual Dashboard
- Category distribution with horizontal bar charts
- Creation activity sparkline
- Top tags frequency visualization
- Quick stats at a glance

### Gap Analysis
- Underrepresented categories
- Missing tag categories
- Suggestions for portfolio balance

### Inspiration Engine
- Random algorithm feature
- Category-specific suggestions
- Related concept recommendations

## Design Principles

1. **Visual first** — Charts over tables, bars over numbers
2. **Emoji semantic** — Category icons for quick recognition
3. **Actionable** — Every insight leads to a next step
4. **Fast** — No heavy computation, instant results

## The Rams Test

1. **Innovative** — Visual analytics for creative portfolios
2. **Useful** — Answers "what should I create next?"
3. **Aesthetic** — Clean charts, consistent styling
4. **Understandable** — Emoji + color coding
5. **Unobtrusive** — Runs when needed, no background tasks
6. **Honest** — Shows real data, real gaps
7. **Long-lasting** — Pure bash, no dependencies
8. **Thorough** — Multiple analysis angles
9. **Environmentally friendly** — Minimal resource usage
10. **Less design** — Four commands, focused purpose
