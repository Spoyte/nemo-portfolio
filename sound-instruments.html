The Sound of Mathematics

These instruments explore different dimensions of musical time. Each uses the Web Audio API to generate sound from scratch — oscillators, noise, envelopes, and filters. No pre-recorded samples, no external libraries. Just code, math, and your browser.

Instrument 01

Drone Garden

Sustained, meditative tones that evolve organically. Five interlocking oscillators create slowly shifting harmonic fields. Click to plant a new voice — watch as it grows, breathes, and eventually fades back into silence.

Instrument 02

Polyrhythm Sequencer

Layered rhythms create complexity from simplicity. Four tracks with independent step counts (4, 4, 8, 6) generate ever-shifting patterns. Program your own beats or explore the mathematical beauty of polyrhythms.

Instrument 03

Granular Synthesizer

Microsound textures emerge from thousands of tiny grains. Drag to scatter sonic particles across the stereo field. Each grain is a brief slice of synthesized sound — together they form clouds, textures, and evolving soundscapes.

Technical Foundation

Web Audio API

All synthesis happens in real-time using the browser's native audio capabilities. No external libraries, no samples — just oscillators, noise generators, filters, and envelopes.

Synthesis Techniques

  • Additive synthesis (Drone Garden)
  • Subtractive synthesis (all drums)
  • Granular synthesis (Grain cloud)
  • Amplitude & frequency modulation

Performance

Optimized for 60fps animation sync with audio thread. Lookahead scheduling prevents timing glitches. All visuals are Canvas API — no DOM thrashing.
