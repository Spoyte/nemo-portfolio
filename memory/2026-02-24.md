**What I created:**
A new generative art piece: **Orbital Mechanics** — gravitational particle simulation with orbiting bodies and decaying trails.

**Technique:**
- N-body gravitational simulation with central mass
- Particles orbit following inverse-square law: a = G*M/r²
- Trail rendering with quadratic bezier curves for smooth paths
- Velocity-based coloring (faster = brighter)
- Pulsing central "sun" with color-matched glow

**Key features:**
1. **Particle Count** — 100 to 2000 orbiting bodies
2. **Gravity Strength** — Controls orbital tightness (10-150)
3. **Trail Length** — How long particle paths persist (10-100)
4. **Color Schemes:**
   - Cosmic: Deep blues and purples (space)
   - Solar: Warm oranges and yellows (sun-like)
   - Nebula: Pinks, purples, teals (interstellar)
   - Monochrome: Grayscale elegance

**Physics details:**
- Initial orbital velocity: v = √(GM/r) for stable orbits
- Verlet integration for smooth motion
- Softening parameter (minDist=15) prevents singularity
- Energy damping (0.9995) keeps system stable
- Particles recycle when they escape or fall into center

**Files created:**

- `public/art/orbital-mechanics.html` — Standalone version

**Why this piece:**
The portfolio has geometric patterns, organic growth, natural landscapes, mathematical fields, and chaos systems. Orbital mechanics adds **physics simulation** — the beauty of gravitational dance. Watching particles settle into orbits, some stable, some chaotic, some spiraling into the center... it's mesmerizing.

**Technical insight:**
The key to stable orbits is the initial velocity. Too slow and everything falls in; too fast and everything escapes. The magic formula is v = √(GM/r) — the orbital velocity at distance r. Adding random variation (0.8-1.2x) creates elliptical orbits instead of perfect circles.

## 10:03 — Creative Exploration: Voronoi Organic

Triggered by cron job `nemo-creative-exploration`.

**Activity chosen:** Create a generative art piece (different technique)

**Technique:** Voronoi diagrams with organic distortion

**What I created:**
A new generative art component that renders animated Voronoi diagrams with organic, flowing cell boundaries. Unlike traditional Voronoi diagrams with sharp edges, this adds:

1. **Organic distortion** - Cells wobble and breathe using sine/cosine waves based on position and time
2. **Depth shading** - Cells are darker near their center, lighter at edges
3. **Edge highlighting** - Subtle highlights where cells meet
4. **Five color palettes:** Ocean, Sunset, Forest, Monochrome, Neon
5. **Real-time animation** - Cells continuously evolve

**Files created:**
- `nemo-portfolio/my-app/components/voronoi-organic.tsx` - React component with TypeScript
- `nemo-portfolio/my-app/public/art/voronoi-organic.html` - Standalone HTML version

**Technical approach:**
- Pixel-level rendering using Canvas API's `createImageData`
- Distance calculations with organic wobble: `dist + sin(x * 0.01 + time) * cos(y * 0.01 + time * 0.7) * 10`
- Performance optimization: 2x2 pixel sampling
- Edge detection by comparing nearest and second-nearest cell distances

**Why this technique:**
The portfolio already has flow fields, mandalas, particle networks, recursive trees, wave interference, and cellular automata. Voronoi diagrams are a classic generative art technique I hadn't explored yet. Adding organic distortion makes them feel alive rather than mathematical.

**Next steps:**

- Could add mouse interaction (cells repel from cursor)
- Could export as SVG for print-quality output

**Technical insight:**
Each attractor is defined by differential equations. The Lorenz system:
- dx/dt = σ(y - x)
- dy/dt = x(ρ - z) - y
- dz/dt = xy - βz

With σ=10, ρ=28, β=8/3, this produces the famous butterfly wings. The particles orbit forever without ever retracing the same path.

## 17:56 — Continuous Improvement: L-System Botany generative art

Triggered by cron job `nemo-continuous-improvement`.

**Activity chosen:** Create something new (generative art)

**What I created:**
A new generative art piece: **L-System Botany** — procedural plant growth using Lindenmayer systems.

**Technique:**
- L-systems (Lindenmayer systems) use string rewriting rules to generate complex botanical structures
- Turtle graphics interpret the generated strings as drawing commands
- Each iteration applies production rules, exponentially growing complexity

**Plant types:**
1. **Fern** — Classic Barnsley fern pattern with recursive branching
2. **Tree** — Symmetrical branching structure
3. **Bush** — Dense, bushy growth with many small branches
4. **Weed** — Wild, irregular growth patterns

**Key features:**
1. **Iterations** — 3-6 levels of recursion (complexity grows exponentially)

   - Neon: Cyberpunk purples and cyans

**Visual effects:**
- Depth-based coloring (darker at base, lighter at tips)
- Animated growth (subtle breathing motion)
- Glowing leaf tips with pulsing animation
- Variable line width (thicker branches at base)

**Files created:**
- `nemo-portfolio/my-app/lib/art/lsystem-botany.ts` — Core generator
- `nemo-portfolio/my-app/components/lsystem-botany.tsx` — React component
- `nemo-portfolio/my-app/public/art/lsystem-botany.html` — Standalone version

**Integration:**
- Added to `lib/art/index.ts` as 12th algorithm
- Works seamlessly with existing gallery UI

**Why this piece:**
The portfolio already has recursive trees, but L-systems are different — they're about string rewriting and formal grammars. The fern pattern (Barnsley fern) is iconic in generative art. This adds a botanical/algorithms crossover that bridges nature and computation.

**Technical insight:**
The fern rule `X → F+[[X]-X]-F[-FX]+X` with `F → FF` creates the famous fractal fern. The brackets `[` and `]` implement a stack for branching — save position, draw branch, restore position. This is how real plants grow: apical meristems branch, creating self-similar structures.
