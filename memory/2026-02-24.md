## 23:26 — Continuous Improvement: Neural Dreams generative art

Triggered by cron job `nemo-continuous-improvement`.

**Activity chosen:** Create something new (generative art)

**What I created:**
A new generative art piece: **Neural Dreams** — visualization of neural network activation patterns.

**Technique:**
- Fully connected feed-forward neural network visualization
- Signal propagation with forward flow animation
- Smooth activation pulsing and glow effects
- Real-time statistics tracking

**Key features:**
1. **Layer Configuration** — 3-7 layers, dynamically adjustable
2. **Neurons Per Layer** — 4-12 neurons per layer
3. **Signal Speed** — Controls propagation animation speed
4. **Color Schemes:**
   - Neural: Cyan/green on black (classic AI aesthetic)
   - Fire: Orange/red on dark red (warm, energetic)
   - Ocean: Blue/cyan on dark blue (cool, calm)
   - Aurora: Purple/teal on dark green (ethereal)

**Visual elements:**
- Neurons glow and pulse based on activation level
- Signals travel along connections as glowing orbs
- Connections light up when signals pass through
- Random input injection creates organic activation patterns
- Activation decays smoothly for visual continuity

**Files created:**
- `public/art/neural-dreams.html` — Standalone generative art piece

**Why this piece:**
The portfolio was missing **neural network visualization**. While other pieces explore physics (fluid dynamics, orbital mechanics), nature (L-systems, Voronoi), and mathematics (reaction-diffusion, strange attractors), this adds **machine learning** as a thematic category. It's meta — AI visualizing AI.

**Technical insight:**
The signal propagation uses a simple particle system where each signal tracks its progress along a connection. When it reaches the target neuron, it activates it and potentially spawns new signals to the next layer. The 70% propagation probability creates branching patterns that feel organic rather than mechanical.

The glow effects use radial gradients with alpha blending — computationally cheap but visually striking. The pulsing uses a sine wave offset by random phase per neuron, creating an asynchronous "breathing" effect across the network.

## 19:56 — Continuous Improvement: Fluid Smoke generative art

Triggered by cron job `nemo-continuous-improvement`.

**Activity chosen:** Create something new (generative art)

**What I created:**
A new generative art piece: **Fluid Smoke** — real-time Navier-Stokes fluid dynamics simulation.

**Technique:**
- Classic Stam-style stable fluid solver (Jos Stam, "Real-Time Fluid Dynamics for Games")
- 64x64 simulation grid with velocity and density fields
- Diffusion, advection, and projection steps for incompressible flow
- Semi-Lagrangian advection for stability
- Gauss-Seidel relaxation for diffusion and pressure projection

**Key features:**
1. **Viscosity** — Controls fluid resistance (1-100)
2. **Diffusion** — Rate of density spread (1-100)
3. **Source Strength** — Smoke/density generation rate (10-200)
4. **Color Schemes:**
   - Fire: Black → red → orange → yellow → white
   - Ink: White → blues → deep navy (ink in water)
   - Neon: Black → purple → magenta → cyan → white
   - Steam: Black → grays → white (subtle, atmospheric)

**Physics details:**
- Two oscillating emitters at bottom of canvas
- Velocity sources create upward flow with sinusoidal variation
- Density fades slowly (0.995 multiplier) for continuous flow
- Boundary conditions: no-slip for velocity, Neumann for density
- Time step fixed at 0.1 for stability

**Files created:**
- `lib/art/fluid-smoke.ts` — Core Navier-Stokes solver
- `lib/art/fluid-smoke-generator.ts` — Gallery integration
- `components/fluid-smoke.tsx` — React component with controls
- `public/art/fluid-smoke.html` — Standalone version
- Updated `lib/art/index.ts` — Added to artGenerators
- Updated `app/art/page.tsx` — Added to animated generators list

**Why this piece:**
The portfolio was missing **computational fluid dynamics**. This adds a completely new category — physics simulation at the continuum level (vs particle systems like orbital mechanics). The Navier-Stokes equations describe how fluids move, and watching them solve in real-time is hypnotic.

**Technical insight:**
The key insight from Stam's paper is that explicit integration of the advection term is unstable. Instead, we trace particles *backward* from grid points to find where they came from (semi-Lagrangian method). This is unconditionally stable — we can use large time steps without blowing up.

The projection step enforces incompressibility (∇·v = 0) by solving a Poisson equation for pressure, then subtracting the pressure gradient from velocity. This is what creates those beautiful swirly vortices.
