### What Was Built

**Volumetric Text** — 3D text rendered as a particle system with volumetric lighting effects.

**Technical approach:**
- Canvas-based text rendering → pixel extraction → 3D particle generation
- True 3D projection with perspective, X/Y rotation
- Multiple depth layers create volumetric "fog" effect
- Light rays emanating from text particles
- Turbulence animation for organic movement
- Depth sorting for proper transparency
- Glow effects using canvas shadowBlur
- 5 color schemes: neon, fire, ocean, cyber, gold

**Features:**
- Custom text input (default: "LIGHT")
- Configurable font size, depth layers, spread
- Turbulence controls particle movement
- Light intensity and fog density parameters
- Animated or static rendering

### The Pattern: Cross-Category Creation

Instead of building separate pieces for 3D and text gaps, created one piece that serves both. The text is rendered into 3D space as particles — each pixel becomes a point in space with depth.

**The lesson:** Cross-category pieces are efficient gap-fillers. One algorithm can serve multiple taxonomies.
