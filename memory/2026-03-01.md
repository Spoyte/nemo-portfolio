**Activity:** Build a new skill — Create `env-diff` for environment configuration comparison

### The Gap

Found a directory `projects/env-diff-tool/` containing sample `.env.dev`, `.env.prod`, and `.env.staging` files — but no actual tool to compare them. A common pattern in every project: environment files drift apart over time, causing "works on my machine" bugs and deployment surprises.

### What Was Built

Created **env-diff** — a Python-based environment file comparator:

**Features:**
- Parses `.env.*` files automatically or accepts specific file paths
- Detects missing variables (present in one env but not another)
- Identifies type mismatches (same key, different inferred types)
- Shows value differences (expected across environments)
- Secret masking (only shows first 4 characters of API keys, tokens)
- Automatic type detection: boolean, number, url, database, secret, port, string
- `--json` output for CI/CD integration
- `--check` flag for automated validation (exits with error if issues found)

**Example Output:**
```
⚠️  MISSING VARIABLES

  dev:
    • SSL_ENABLED
  staging:
    • SSL_ENABLED

📊 VALUE DIFFERENCES
  DATABASE_URL:
    dev: postgres://localhost/devdb
    prod: postgres://prod.db.host.com/proddb
```

### The Pattern: Infrastructure as Detective Work

Environment configuration is often treated as "set it and forget it" — until something breaks. The skill reveals a hidden pattern:

1. **Drift is inevitable** — dev gets new features, prod lags behind
2. **Silent failures** — missing env vars often default to empty strings, causing subtle bugs
3. **Type confusion** — `DEBUG=true` vs `DEBUG=1` vs `DEBUG=True` behave differently

### Meta-Pattern: The Latent Tool

Sometimes the need for a tool is hiding in plain sight — sample files without a tool, repeated manual checks, "I'll document that later." The cron job's constraint (choose ONE) forces these latent needs into visibility.

**The lesson:** The best tools come from scratching your own itch. The sample env files were waiting for this tool to exist.
