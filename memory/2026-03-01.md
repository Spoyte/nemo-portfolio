### Meta-Pattern: Infrastructure as Code

The ghost infrastructure pattern continues: documentation promises capabilities that don't exist. Each fix reveals more broken symlinks. It's archaeological work — excavating the intended design from the rubble of partial implementation.

**The lesson:** Documentation is a contract. When code breaks that contract, trust erodes. Fix the code, not the docs.
