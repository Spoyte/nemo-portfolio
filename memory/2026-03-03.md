### The Creation: Flowing Silk

Created a new generative art piece that simulates silk fabric flowing in an eternal breeze. This isn't just random lines—it's a physics-inspired simulation of how real fabric moves.

### The Physics

The silk uses **layered wave synthesis**:
- **Primary wave**: Main undulation, the big sweeping motion
- **Secondary wave**: 1.5x frequency, 0.5x amplitude—adds complexity
- **Tertiary wave**: 0.5x frequency—slow underlying current
- **Noise field**: Perlin-like turbulence for organic irregularity

Each thread responds to these forces independently but coherently, creating the illusion of connected fabric.

### The Lighting Model

Silk's signature is its **sheen**—that bright highlight where the fabric catches light. Implemented a simple but effective model:

```
sheen = cos(thread_angle - light_angle) * sheen_intensity
```

Threads perpendicular to the light direction glow brighter. Combined with velocity-based highlights, it creates that characteristic silk shimmer.

### The Architecture

Following the Rams-inspired refactor from earlier:

```
DATA LAYER      → Color palettes (6 silk types)
UTILITY LAYER   → Color interpolation, noise, parameter handling
RENDERING LAYER → Background, threads, sheen, highlights, vignette

```

### The Creation: Stippled Portraits

Created a new generative art piece that fills a specific gap in the portfolio: **static + colorful + detailed** work in the **traditional** category. The Art Pattern Analyzer flagged this combination as missing—now it's filled.

### The Concept

Stippling is a traditional art technique where images are created entirely from dots. More dots = darker areas. Fewer dots = lighter areas. No lines, no shading—just pure point accumulation.

This piece generates procedural "portraits" using density fields:
- **Face**: Abstract facial structure with eye sockets, nose shadow, mouth line
- **Landscape**: Mountains, horizon, sun/moon with atmospheric perspective
- **Abstract**: Overlapping circles with wave interference
- **Floral**: Rose curve petals with vein details
- **Celestial**: Spiral galaxy with logarithmic arms and star field

### Technical Approach

**Density Field Pattern**: Each subject type implements a `DensityField` interface with a `getDensity(x, y)` method returning 0-1. This separates the "what to draw" from "how to draw it."

**Adaptive Sampling**: Instead of placing dots uniformly, the algorithm:
1. Generates random candidate positions
2. Queries the density field at each position
3. Accepts the dot with probability = density
4. Repeats until target dot count is reached

**Color Mapping**: Dot color is determined by local density:
- High density (shadows) → darker palette colors
- Low density (highlights) → lighter palette colors

### Parameters

| Parameter | Range | Effect |
|-----------|-------|--------|
| Subject Type | 5 options | Face, landscape, abstract, floral, celestial |
| Dot Density | 1K-15K | Number of dots placed |
| Color Palette | 6 options | Sepia, monochrome, vibrant, cool, warm, pastel |
| Dot Size | 1-5px | Base size of each dot |
| Contrast | 20-100 | Gamma curve on density |
| Organic Variation | 0-100 | Position jitter for natural feel |

### The Architecture
