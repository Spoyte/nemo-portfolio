### The Refactoring

Took `textile-weave.ts` from a 200-line monolith to a layered architecture. The original had:
- Duplicated hex-to-rgb parsing (4x)
- Scattered `as string`/`as number` casts (10x)
- Mixed concerns: data, rendering, and logic all tangled
- Magic numbers without context

### The New Architecture

```
DATA LAYER      → Constants, types, lookup tables
UTILITY LAYER   → Color parsing, parameter handling  
RENDERING LAYER → Composable drawing functions
PUBLIC API      → Clean interface, backward compat
```

### Key Improvements

1. **Color cache** — Parsed RGB values cached, eliminating redundant `parseInt` calls
2. **`getParam()` utility** — One place for type-safe parameter extraction
3. **`RenderContext`** — Bundle all render state, stop passing 8 parameters
4. **Single-responsibility functions** — `drawWarpThreads()`, `drawWeftThreads()`, etc.
5. **Type safety** — Added `ColorPalette` interface, removed blind casting

### The Creation: Flowing Silk

Created a new generative art piece that simulates silk fabric flowing in an eternal breeze. This isn't just random lines—it's a physics-inspired simulation of how real fabric moves.

### The Physics

The silk uses **layered wave synthesis**:
- **Primary wave**: Main undulation, the big sweeping motion
- **Secondary wave**: 1.5x frequency, 0.5x amplitude—adds complexity
- **Tertiary wave**: 0.5x frequency—slow underlying current
- **Noise field**: Perlin-like turbulence for organic irregularity

Each thread responds to these forces independently but coherently, creating the illusion of connected fabric.

### The Lighting Model

Silk's signature is its **sheen**—that bright highlight where the fabric catches light. Implemented a simple but effective model:

```
sheen = cos(thread_angle - light_angle) * sheen_intensity
```

Threads perpendicular to the light direction glow brighter. Combined with velocity-based highlights, it creates that characteristic silk shimmer.

### The Architecture

Following the Rams-inspired refactor from earlier:

```
DATA LAYER      → Color palettes (6 silk types)
UTILITY LAYER   → Color interpolation, noise, parameter handling
RENDERING LAYER → Background, threads, sheen, highlights, vignette
PUBLIC API      → Clean ArtPiece interface
```

### Parameters

| Parameter | Range | Effect |
|-----------|-------|--------|
| Thread Density | 20-100 | How many parallel threads |
| Flow Speed | 0-100 | How fast the silk moves |
| Turbulence | 0-100 | Noise influence on waves |
| Wave Height | 10-100 | Amplitude of undulations |
| Silk Sheen | 0-100 | Highlight intensity |

- **Midnight**: Deep blue silk, like evening wear
