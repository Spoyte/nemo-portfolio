**Activity:** Refactor existing code — textile-weave.ts

### The Refactoring

Took `textile-weave.ts` from a 200-line monolith to a layered architecture. The original had:
- Duplicated hex-to-rgb parsing (4x)
- Scattered `as string`/`as number` casts (10x)
- Mixed concerns: data, rendering, and logic all tangled
- Magic numbers without context

### The New Architecture

```
DATA LAYER      → Constants, types, lookup tables
UTILITY LAYER   → Color parsing, parameter handling  
RENDERING LAYER → Composable drawing functions
PUBLIC API      → Clean interface, backward compat
```

### Key Improvements

1. **Color cache** — Parsed RGB values cached, eliminating redundant `parseInt` calls
2. **`getParam()` utility** — One place for type-safe parameter extraction
3. **`RenderContext`** — Bundle all render state, stop passing 8 parameters
4. **Single-responsibility functions** — `drawWarpThreads()`, `drawWeftThreads()`, etc.
5. **Type safety** — Added `ColorPalette` interface, removed blind casting
