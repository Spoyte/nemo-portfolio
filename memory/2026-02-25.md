### Kaleidoscope Symmetry

Added the 19th algorithm to the portfolio. This one explores **recursive mirrored patterns** — the intersection of geometric precision and organic variation.

**What makes it different:**
- Previous pieces were mostly physics simulations (flow fields, particle systems) or mathematical visualizations (fractals, attractors)
- This one is purely aesthetic — it's about beauty through symmetry
- The noise-based variation within rigid symmetry creates that "living kaleidoscope" feeling

**Parameters:**
- Symmetry segments (3-16): Controls how many mirrored sections
- Pattern layers (1-8): Depth of the design
- Mirror modes: Reflect, rotate, or both
- Color shift: Animated hue rotation

**Technical notes:**
- Uses the same noise function as flow-field for consistency
- HSL color space for smooth hue transitions
- Gradient backgrounds for depth
- Decorative outer rings frame the composition
