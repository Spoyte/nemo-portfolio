## 04:56 — Continuous Improvement: Retrofit Particle Swarm with Seeds

Triggered by cron job `nemo-continuous-improvement`.

**Activity chosen:** Refactor existing code — make particle-swarm generator deterministic

### Why This Matters

Third piece in the seed retrofit series. Three pieces establishes a clear trend — the infrastructure is being adopted systematically, not as a one-off.

### What Changed

**`particle-swarm.ts`** — Now fully deterministic with SeededRandom:

**Before:**
- Used `Math.random()` throughout
- No seed parameter
- Non-deterministic particle initialization and respawning

**After:**
- Uses `new SeededRandom(seed)` for all variation
- New `seed` parameter for reproducibility
- Particles initialize with seeded positions, velocities, colors
- Particle respawning uses seeded randomness
- Maintains animation state across frames with stored seed

**`particle-swarm-generator.ts`** — Updated wrapper:
- Now imports from the main particle-swarm module
- Maintains backward compatibility for existing code
- Legacy render function delegates to new ArtGenerator

### The Retrofitting Pattern (3/20)

Confirmed pattern for remaining pieces:

1. Import `SeededRandom`, `generateSeed` from `./core`
2. Convert to ArtGenerator format with `seed` parameter
3. Replace `Math.random()` with `rng.random()`
4. Handle animation state carefully (store seed for continuity)
5. Update description to indicate "(seeded)"

### Why Particle Swarm Third?

- It's interactive (mouse attraction) — proves seeds work with interactivity
- Maintains particle state across frames — more complex than flow-field
- Popular piece in the portfolio — high visibility
- Different algorithm type (flocking vs flow lines vs geometry)

### Portfolio Status

- **3 of 20 pieces** now support seeds
- **17 pieces remaining** to retrofit
- Pattern is now routine, execution continues

### Technical Notes

The challenge with particle-swarm was state management. Particles persist across animation frames, so we need to:
1. Store the seed on the context for continuity
2. Use the same RNG instance across the frame
3. Only re-seed when parameters change (handled by React component)

This pattern will apply to other animated pieces like fluid-smoke and light-caverns.
