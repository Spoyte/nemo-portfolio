# 2026-02-25 — Continuous Improvement Cycle (20:56 PM)

## Activity: Created String Art Generative Piece

### What Was Built

**String Art** — A generative art piece exploring mathematical curve stitching. The 29th piece in the portfolio.

### Features

**Curve types:**
- **Parabola** — Classic string art pattern connecting point i to 2i
- **Hyperbola** — Symmetric curves with offset variations
- **Ellipse** — Closed curves with adjustable eccentricity
- **Cardioid** — Heart-shaped curves with density modulation
- **Spiral** — Expanding patterns with increasing step size

**Visual controls:**
- Anchor points (12-48) defining the circular frame
- Multiple layers with independent radii
- Curve density (20-100 lines per layer)
- 7 color schemes including midnight and gold
- Adjustable line opacity and width
- Animated breathing effect on anchor points

### Technical Approach

**Mathematical foundation:**
String art creates the illusion of curves using only straight lines. The algorithm maps points on a circle and connects them according to parametric rules. Different curve types emerge from different connection patterns.

**Rendering pipeline:**
1. Background (adaptive to color scheme)
2. Anchor points (subtle circles)
3. String layers (back to front)
4. Center decoration with glow

**Animation:**
- Anchor points breathe with sinusoidal offset
- Lines have subtle animated displacement
- Time-based modulation creates organic movement

### Design Decisions

**Why string art?** The portfolio had:
- Physics simulations (boids, orbital, wave interference)
- Natural systems (trees, DLA, reaction-diffusion)
- Mathematical curves (spirograph, Lissajous, strange attractors)
- Geometric patterns (mandala, kaleidoscope, voronoi)
- Optics (crystal refraction — planned)

But nothing exploring the emergent beauty of line-based mathematics. String art is a classic mathematical art form that bridges craft and computation.

**Multiple curve types** — Each mathematical curve (parabola, hyperbola, ellipse, cardioid, spiral) produces distinctly different aesthetics from the same underlying structure. This demonstrates how parametric variation creates visual diversity.

**Layer system** — Multiple concentric layers with different radii create depth and complexity. Each layer can use different colors from the palette.

### Insight

String art is a reminder that constraints breed creativity. The limitation (only straight lines between fixed points) forces interesting solutions. The curves aren't drawn — they're implied by the density of lines. This emergent property is a metaphor for generative art itself: simple rules, complex results.

The "choose ONE" constraint of these cycles has the same effect. Each cycle produces a complete, committed piece. No planning paralysis, no infinite refinement. Just continuous evolution.
