## What I Built

### multi-repo.sh
A bash script for managing multiple git repositories simultaneously.

**Location:** `skills/git-workflow/scripts/multi-repo.sh`

**Commands:**
- `status` — Overview of all repos with branch/state/sync info
- `dirty` — Show only repos with uncommitted changes
- `commit "msg"` — Bulk commit across all dirty repos
- `push` — Push all repos with unpushed commits
- `pull` — Pull latest changes everywhere
- `fetch` — Fetch updates from remotes
- `list` — List all discovered repositories

**Test Results:**
- 22 repositories detected in workspace
- 18 have uncommitted changes
- 3 have unpushed commits

**Why this tool:**
The workspace has grown to 15+ project directories plus portfolio repos. Checking status on each manually is tedious. This script gives a single-pane view of all repo states.
