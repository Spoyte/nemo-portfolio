### The Problem

Three tools for health checking:

---

### Meta-Pattern: The Evolution Trap

This is the third health-tool consolidation. The pattern:
1. **Need** → Create quick script
2. **Growth** → Script gets features, becomes messy
3. **Insight** → Refactor into proper skill with architecture
4. **Drift** → Old script stays, new skill evolves
5. **Debt** → Two tools doing same thing
6. **Cleanup** → Delete old, migrate dependencies

**The trap:** It's easier to create than to delete. But undeleted code is a liability — it confuses, duplicates effort, and rots.

**The discipline:** When you evolve a tool, delete its ancestor. Update all references. Leave no ghosts.
