**Activity:** Refactor existing code — create art-insights analyzer

### What Was Created

**Art Insights Analyzer** (`lib/art/art-insights.ts`) — a self-analysis tool for the generative art portfolio.

### The Problem
The portfolio has grown to 86 algorithms across 9 categories, but there was no systematic way to:
- Identify category imbalances
- Find tag distribution gaps
- Guide future creative decisions

### The Solution
A TypeScript analysis module that:
1. **Categorizes** all 86 pieces against target distributions
2. **Analyzes tags** to find over/under-represented styles
3. **Calculates diversity score** based on balance metrics
4. **Generates recommendations** for filling gaps

### Key Findings

| Metric | Value | Insight |
|--------|-------|---------|
| Total Pieces | 86 | Substantial collection |
| Animated | 74 (86%) | Static pieces underrepresented |
| Interactive | 5/8 target | Gap identified |
| Minimal | 4 pieces | Rare aesthetic |
| Cyberpunk | 1 piece | Opportunity space |
