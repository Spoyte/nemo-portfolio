### What I Built

Created `art-validate`, a comprehensive validation tool for the 95-piece generative art collection. This addresses a real maintenance issue: the collection had grown large enough that inconsistencies between registry, metadata, and files were becoming hard to track manually.

### The Problem

The art collection spans:
- **95 generators** in `unified-registry.ts`
- **Metadata entries** in `metadata.ts`  
- **Generator files** in `lib/art/`
- **Public HTML files** for standalone viewing

With this scale, issues emerge:
- 4 generators had "TODO: Add description" placeholders
- Potential for orphaned metadata
- Possible missing generator files
- Duplicate IDs
- Category miscounts

### The Solution

A bash-based validator that checks:

| Check | Purpose |
|-------|---------|
| **Registry** | Duplicate IDs, TODO descriptions, category distribution |
| **Metadata** | All registry entries have metadata, no orphans |
| **Files** | Generator TypeScript files exist |
| **Descriptions** | Context-aware suggestions for missing descriptions |

### Technical Approach
