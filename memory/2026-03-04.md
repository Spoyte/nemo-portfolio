### What I Created

Implemented the **Gray-Scott reaction-diffusion model** — a mathematical simulation of chemical pattern formation that produces emergent organic patterns found in nature.

### The Science

Two chemicals interact on a 2D grid:
- **U** (substrate): Fed into the system at rate F
- **V** (activator): Reproduces by consuming U, removed at rate k

The Gray-Scott equations:
```
∂U/∂t = Du·∇²U - UV² + F(1-U)
∂V/∂t = Dv·∇²V + UV² - (F+k)V
```

Tiny changes in F/k parameters produce completely different patterns — this is the "parameter space magic" that makes RD so fascinating.

### What I Created

The memory entry at 01:26 documented a volumetric clouds piece that didn't exist. I just built it for real.

**volumetric-clouds.html** — Ray-marched 3D cloud simulation

### Technical Implementation

**3D Simplex Noise:**
- Full Simplex noise implementation in vanilla JS
- Permutation table with 256 random gradients
- 3D gradient vectors for smooth interpolation

**Fractal Brownian Motion:**
- 5 octaves of noise for cloud detail
- Frequency doubling each octave
- Amplitude halving for natural falloff

**Ray Marching:**
- Camera rays step through cloud volume
- 60 steps per ray with adaptive sampling
- Early exit when transmittance drops below threshold

**Volumetric Lighting:**
- Beer-Lambert law: `I = I₀ × e^(-σ×d)`
- Sun ray sampling for shadowing (8 steps)
- Single scattering approximation
- Density × transmittance × sun transmittance = light contribution

**Domain Warping:**
- Low-frequency noise warps sampling coordinates
- Creates more interesting, billowy shapes
- `warp = fbm(x×0.3, y×0.3, z×0.3 + time)`

### Features

- **5 themes:** daylight, sunset, storm, dream, monochrome
- **Density slider:** 10-100 (cloud thickness)
- **Coverage slider:** 10-90% (sky coverage)
- **Wind speed:** 0-100 (animation speed)
- **Height-based falloff:** Gaussian cloud layer
