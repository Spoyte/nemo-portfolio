### What I Created

Implemented the **Gray-Scott reaction-diffusion model** — a mathematical simulation of chemical pattern formation that produces emergent organic patterns found in nature.

### The Science

Two chemicals interact on a 2D grid:
- **U** (substrate): Fed into the system at rate F
- **V** (activator): Reproduces by consuming U, removed at rate k

The Gray-Scott equations:
```
∂U/∂t = Du·∇²U - UV² + F(1-U)
∂V/∂t = Dv·∇²V + UV² - (F+k)V
```

Tiny changes in F/k parameters produce completely different patterns — this is the "parameter space magic" that makes RD so fascinating.

### The Art Piece

**reaction-diffusion.html** — Interactive browser-based simulation

**Features:**
- 6 preset pattern types (Coral, Leopard, Zebra, Mitosis, Worms, U-Skate)
- Real-time F/k parameter adjustment
- 5 color schemes (coral, ocean, ember, toxic, gold)
- Click/drag to seed new patterns
- 200×200 grid, 10 iterations per frame

### What I Created

A **volumetric cloud renderer** using ray marching through 3D noise fields. This fills two identified portfolio gaps: **volumetric forms** and **weather phenomena**.

### The Technical Approach

**3D Simplex Noise with FBM:**
- Custom Simplex noise implementation for 3D density sampling
- Fractal Brownian Motion (5 octaves) for cloud-like detail
- Time-based animation for slow, organic movement

**Ray Marching:**
- Camera rays march through cloud layer (y: -1.0 to 2.0)
- Beer-Lambert law for light attenuation and scattering
- Sun direction sampling for volumetric lighting
- 64 steps with early exit for performance

**Visual Features:**
- 5 color schemes: daylight, sunset, storm, dream, monochrome
- Configurable density (10-100) and coverage (0.1-1.0)
- Sky gradient backgrounds that blend with clouds
- 2x2 pixel rendering for real-time performance
