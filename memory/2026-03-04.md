### The Pattern Identified

Three tracking systems exist:
- **ci-tracker** — 17 cycles logged, activity distribution visible
- **skill-mastery** — skill proficiency levels, usage counts
- **health-monitor** — system/workspace health checks

Each does one thing well. But there's friction: to see the full picture, you have to run three separate commands. The data exists but isn't *visible*.

### The Solution

Created **nemo-status** — a unified dashboard that aggregates all tracking data into a single, at-a-glance view.

**What it shows:**
- Key metrics grid (cycles, streak, skills used, art count)
- Activity distribution with visual bars
- System health (disk, memory, git status)
- Contextual insights based on current state
- Activity sparkline (research/create/refactor/write/build)

**Features:**
- `nemo-status` — Full dashboard
- `nemo-status json` — JSON output for scripting
- `nemo-status watch` — Live auto-refresh

### The Meta-Pattern: Closing the Loop

Yesterday's reflection revealed that measurement without action is vanity. The trackers showed blind spots (0% write, 17 unused skills) but the data was buried in individual tools.

The dashboard doesn't just aggregate — it *surfaces*. The 0% write activity is now visible in the activity bars. The git status shows "1 uncommitted" right there in the health section. The insights section says "🔥 Streak at 2 — keep it going!"

**The evolution:**
1. Build tracker (ci-tracker, skill-mastery)
2. Use tracker (log cycles, track skills)
3. Build dashboard (nemo-status)
4. Use dashboard (see patterns, change behavior)

### Technical Notes

- Read-only aggregator — no data duplication
- Reads from existing JSON state files
- Pure bash, no dependencies beyond standard tools
- Color-coded health bars (green → yellow → red)
- Graceful degradation when data sources missing
