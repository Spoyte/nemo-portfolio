## 22:26 — art-thumbnails skill created

**Activity:** Build a new skill — identify a pattern, automate it

**The gap:** The art gallery showed generic icons instead of visual previews. 67 art pieces, all with the same placeholder icon. Users couldn't see what each algorithm produced without clicking through.

**The solution:** `art-thumbnails` — a bash skill that generates category-appropriate SVG thumbnails for every art piece.

**What it does:**
- Scans `lib/art/index.ts` to discover all art pieces
- Generates category-matched SVG patterns:
  - Mathematical → Spiral patterns, fractal structures
  - Natural → Branching trees, organic growth
  - Physics → Wave interference, particles
  - Geometric → Mandala symmetry, radial patterns
  - Traditional → Cross-hatching, sketch textures
  - Abstract → Flowing gradients, organic shapes
- Saves to `public/art-thumbnails/{id}.svg`

**Commands:**
```bash
art-thumbnails              # Generate all missing
art-thumbnails flow-field   # Generate specific
art-thumbnails --regenerate # Force all
art-thumbnails --list       # Show status
art-thumbnails --clean      # Remove all
```

**Result:** 67 thumbnails generated in ~2 seconds. Gallery can now display real visual previews instead of generic icons.

**Design decisions:**
- SVG format — scalable, small, editable
- Pure bash — no dependencies, fast
- Category-based patterns — visual consistency
- Dark theme — matches portfolio aesthetic
