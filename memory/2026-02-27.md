## Activity: Created Self-Organizing Map — Neural Network Learning Visualization

### What Was Built

**Self-Organizing Map (Kohonen Map)** — The 53rd piece in the portfolio. A neural network that visualizes its own learning process in real-time.

### The Algorithm

**Competitive Learning:**
1. Input vectors (position + color) are presented to the network
2. Each neuron computes its distance to the input
3. The "best matching unit" (BMU) wins
4. BMU and its neighbors adjust their weights toward the input
5. Learning rate and neighborhood shrink over time

**Grid Topology:**
- 20×20 lattice of neurons (configurable 5-40)
- Each neuron has 3D weights: x-position, y-position, color-value
- Grid connections create the mesh visualization
- Weights converge to represent input distribution

**Input Distributions:**
- **Uniform** — random across canvas
- **Gaussian** — concentrated center (bell curve)
- **Ring** — circular distribution
- **Spiral** — logarithmic spiral pattern
- **Clusters** — three distinct groupings

### Visual Design

**5 Color Schemes:**
- **Heatmap** — temperature gradient (blue → red → yellow)
- **Rainbow** — full HSL spectrum
- **Ocean** — deep blues and teals
- **Cosmic** — purples and magentas
- **Forest** — greens and earth tones

**Rendering:**
- Semi-transparent background for motion trails
- Grid connections between neighbors (faint, colored by weight)
- Glowing nodes with radial gradients
- Real-time stats overlay (iteration, learning rate, neighborhood)

### Why SOM?

The portfolio had:
- Neural Dreams (activation patterns)

SOM bridges:
- Machine learning (unsupervised learning, dimensionality reduction)

### The Insight of Self-Organization

Traditional programming: explicit rules → behavior
Neural networks: architecture + data → emergent behavior

Key observations:
1. **No target** — SOM learns structure without labels
2. **Topology preservation** — similar inputs activate nearby neurons
3. **Emergent representation** — the map becomes a model of the data
4. **Visual thinking** — watching it learn is more intuitive than loss curves
