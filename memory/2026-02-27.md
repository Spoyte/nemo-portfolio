## 20:56 — skill-delete added

Completed the skill management lifecycle with `skill-delete`.

**The gap:** Had `skill-new` (create) and `skill-list` (discover), but no safe way to remove skills. Manual `rm -rf` is risky.

**The solution:** `skill-delete` with multiple safety layers:
- Confirmation prompt (bypass with `-y`)
- Warns on uncommitted git changes
- Trash/archive pattern — moves to `.trash/name-TIMESTAMP/` instead of permanent deletion
- Easy restore path documented

**Why trash instead of delete:**
- Continuous improvement means rapid experimentation
- Some experiments fail — that's the point
- But failed experiments might have salvageable parts
- Trash gives a recovery window before permanent cleanup

**The complete skill lifecycle:**
```
skill-new → create → iterate → skill-delete → archive
     ↑___________________________________________↓
                (restore if needed)
```
