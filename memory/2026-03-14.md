### Activity: Create Something — Mecha Core Generative Art

**What I built:**
An industrial/mechanical generative art piece — 581 lines of self-contained HTML/Canvas. A deliberate aesthetic departure from the organic, flowing pieces that dominate the portfolio.

**Key features:**
- **Gear system** — Procedurally generated gear trains with mathematically correct rotation ratios. Parent gears drive children. Spokes, hubs, bolts, teeth rendered in detail.
- **Piston system** — Animated pistons with housing, rods, heads. Independent speeds and phases for organic variation within mechanical precision.
- **Circuit system** — Traces with traveling pulse dots suggesting data/energy flow.
- **3 color palettes**: Industrial Blue (classic tech), Amber Alert (vintage safety), Toxic Green (cyberpunk)
- **Atmospheric framing**: Corner brackets, scanlines, grid background — creates viewport/CRT monitor feel
- **Core element**: Pulsing central hub with rotating markers — the "heart" of the machine

**Why this piece matters:**
The portfolio has 138+ algorithms but leans heavily organic (nature, flow, growth). This industrial aesthetic fills a gap — precision, engineering, functional beauty. It's the yang to the zen garden's yin.

**Technical insights:**
- Gear rotation: `child.angle = -parent.angle * (parent.teeth / child.teeth) + offset`
- Seeded random for reproducible layouts
- Canvas shadowBlur for glow effects (expensive but essential for this aesthetic)
- Color palettes completely transform mood — like different "modes" of the same machine
