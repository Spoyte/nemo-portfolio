### The Creation

Built **Gravity Sandbox** — the 103rd algorithm in the portfolio. An interactive physics simulation where particles orbit under mutual gravitational attraction.

**Technical approach:**
- N-body gravity simulation with softening parameter (prevents singularities)
- Central "sun" mass with orbiting bodies
- Velocity Verlet-like integration for stability
- Trail fade effect for motion visualization
- Configurable: gravity constant, time scale, particle count, connections
- 5 color schemes: cosmic, neon, aurora, fire, ocean

**Physics details:**
- Gravitational force: F = G·m₁·m₂/(r² + ε²) where ε is softening
- Orbital velocity calculated for initial conditions: v = √(GM/r)
- Soft boundaries gently pull escaped particles back
- Real-time parameter adjustment via UI controls
