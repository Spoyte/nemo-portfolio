### Hypercube

Created **Hypercube** — the 77th algorithm in the portfolio. A rotating 4D tesseract (hypercube) projected into 3D and then 2D space.

**Technical approach:**
- 16 vertices in 4D space (each coordinate ±1)
- 32 edges connecting vertices that differ in one coordinate
- 6 rotation planes in 4D: XY, XZ, XW, YZ, YW, ZW
- Combined rotations create complex, mesmerizing motion
- 4D → 3D perspective projection (along W axis)
- 3D → 2D perspective projection (along Z axis)
- Depth-based rendering (back-to-front for proper occlusion)
- Glow effects for neon and fire themes

**Why this piece matters:**
The portfolio analysis flagged "3d" as underrepresented (4 pieces). This brings it to 5 pieces — and more importantly, it's the first true 4D visualization. Most "3D" art is 3D projected to 2D. This is 4D projected to 3D projected to 2D. The extra dimension adds something qualitatively different.

**Design decisions:**
- Multiple simultaneous rotations prevent periodic repetition
- Color schemes match the dimensional theme (neon = futuristic, matrix = digital)
- Inner cube rendered with dashed lines emphasizes the 4D structure
- Vertex size varies by depth (perspective cue)
- Edge opacity varies by depth (atmospheric perspective)

**The Rams Test:**
1. ✓ Innovative — 4D visualization is rare in generative art
2. ✓ Useful — fills 3D category gap
3. ✓ Aesthetic — mesmerizing motion, clean geometry
4. ✓ Understandable — edges and vertices are intuitive
5. ✓ Unobtrusive — smooth rotation, no jarring changes
6. ✓ Honest — shows projection artifacts, reveals structure
7. ✓ Long-lasting — mathematical beauty is timeless
8. ✓ Thorough — 5 color schemes, 2 projection modes, 3 rotation speeds
9. ✓ Environmentally friendly — pure math, no textures/assets
10. ✓ Less design — just vertices, edges, rotation

**Portfolio evolution:**
- 76 → 77 algorithms
