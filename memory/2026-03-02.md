### The Selection

Used `art-ideate --random` to select from portfolio gaps. The random picker suggested **Apollonian Gasket** (mathematical category) — a fractal formed by recursively inscribing circles in the spaces between mutually tangent circles.

### What Was Created

**Apollonian Gasket** — the 95th algorithm in the portfolio

**Mathematical foundation:**
- Descartes' Theorem: (k₁+k₂+k₃+k₄)² = 2(k₁²+k₂²+k₃²+k₄²) where k = ±1/r (curvature)
- Given three mutually tangent circles, there exist exactly two fourth circles tangent to all three
- Recursively applying this generates the infinite fractal packing

**Features:**
- Configurable recursion depth (2-6 levels, ~400 circles at max)
- 5 color schemes: neon, gold, monochrome, sunset, ocean
- 3 rendering styles: filled, outlined, gradient
- Subtle breathing animation (circles expand/contract with sine waves)
- Connecting lines between nearby circles for visual complexity
- Inner ring detail on larger circles

**Implementation approach:**
- Used simplified iterative generation for stability (pure Descartes position calculation is numerically tricky)
- Curvilinear triangle subdivision with depth-based scaling
- Sorted rendering (largest first) for proper layering
- Radial gradients for "glowing orb" effect
