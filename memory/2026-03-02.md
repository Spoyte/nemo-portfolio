### What Was Built

**backup-restore** — Complete data protection skill

**Commands:**
- `backup-now` — Create timestamped backup with manifest
- `backup-status` — Health check with age warnings
- `backup-list` — List available backups
- `backup-restore <name>` — Safe restoration with safety backup

**Features:**
- Manifest JSON tracks files, size, timestamp
- Git remotes saved for restoration
- Automatic rotation (keeps 7 most recent)
- Dry-run mode for safety
- Safety backup created before any restore
- JSON output for scripting
