### Raymarcher

Created **Raymarcher** — the 83rd algorithm in the portfolio. A true 3D renderer using raymarching with signed distance functions (SDFs).

**Technical approach:**
- Real-time raymarching through 3D space
- 4 SDF primitives: sphere, box, torus, mandelbulb
- 5 color palettes (neon, gold, cyber, sunset, matrix)
- Soft shadows using secondary raymarching
- Ambient occlusion for depth cues
- Dual-axis rotation animation
- Fog for atmospheric depth

**Why this piece matters:**
The portfolio analysis flagged "3d" as underrepresented (5 pieces, 6%). This brings it to 6 pieces (7%) — progress toward better balance. More importantly, this is the first true raymarcher in the collection. Previous 3D pieces used wireframes or simple projections. This one actually renders 3D surfaces with lighting.

**Design decisions:**
- Pixel-level rendering via ImageData for performance
- Vector3 math library for clean 3D operations
- SDF composition for extensibility
- Color based on surface position + time for dynamic feel
- Adjustable density for quality/performance tradeoff
