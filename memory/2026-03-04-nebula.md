### What I Created

A **procedural nebula generator** that creates volumetric cosmic cloud formations using fractal Brownian Motion (FBM) noise. This adds a fifth piece to the 3D category, which was the smallest in the portfolio.

### The Technical Approach

**Volumetric Cloud Rendering:**
- FBM-based density fields for organic cloud structures
- Multi-octave noise layering (large, medium, fine detail)
- Position-based color sampling from themed palettes
- Real-time evolution via time-based noise offset

**Five Nebula Types:**

| Type | Palette | Character |
|------|---------|-----------|
| **Emission** | Red, orange, yellow, purple, blue | Classic HII regions like Orion |
| **Reflection** | Blues, whites, periwinkle | Scattered starlight like Pleiades |
| **Dark** | Deep purples, near-black | Dust lanes blocking light |
| **Planetary** | Greens, cyans, golds | Shells of dying stars |
| **Supernova** | White, gold, orange, red, purple | Explosive stellar remnants |

**Star Field System:**
- Procedurally generated star positions
- Twinkling animation with phase offsets
- Size-based glow effects
- Configurable density (0-200 stars)

**Performance Optimizations:**
- Half-resolution sampling with upscaling
- Pixel manipulation via ImageData
- Efficient alpha blending
